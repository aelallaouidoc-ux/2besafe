# 2besafe
This repository contains the source code of the 2BeSafe mobile application developed with Flutter, which enables real-time visualization and monitoring of physiological data collected from the smart patch prototype. The project also includes the machine learning training scripts, a sample dataset used for model development, and the inference module used to classify physiological conditions and estimate worker risk levels. Together, these components demonstrate the complete workflow of the 2BeSafe system, from data acquisition and model training to real-time inference and mobile visualization.
